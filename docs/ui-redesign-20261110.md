# 账号授权工作台 UI · 九轮优化记录

日期：2026-11-10

## 方向与范围

管理员用于 OpenAI 账号授权、2FA 更换和 Sub2API 导入的运维工作台。方向经用户确认：沉稳、精确、利落；保留浅色与深绿色，使用浅石墨中性色和白色工作面。

覆盖登录页、恢复会话界面、主导航、账号列表、配置弹窗、共享控件及设置页。功能、业务流程和章节顺序沿用原有实现。视觉重点是预计可用时间的大读数和真实任务驱动的六步进度轨道。

原界面没有渐变、发光或装饰 emoji；主要问题是重复卡片、固定列宽遮挡时间、同权重操作按钮、长弹窗提交区不可见，以及字号、图标、圆角不统一。

## 九轮落地

1. **间距**：页面边距统一为16/32px，面板20/24px，组间距24px。共享按钮与输入框保持44px高度，设置页检测间隔改为标题与字段横向对齐。
2. **颜色**：将 slate 色阶统一为轻微偏绿的中性灰。主动作沿用深绿，边框与背景减弱；可持续、将耗尽和样本不足分别使用绿色、琥珀色和中性读数，状态仍有文字说明。
3. **图标**：沿用 Lucide，统一18px与1.5描边。按钮弱化边框，授权操作增加文字标签，删除操作与其他动作拉开距离。
4. **文案**：页面标题明确为“账号管理”“工作台设置”；统计口径保留完整内容，改为可展开说明。登录入口注明授权与凭据管理，操作标签沿用已有业务名称。
5. **字体**：显式指定中文系统无衬线回退；主标题24px、主要读数28/32px、正文14px、辅助信息12px。字重400/500为主，表格与数值使用等宽数字。
6. **布局**：用量区从等宽嵌套卡片改为两项数字与更宽的可用时间读数。表格减少列宽浪费，完整显示最近检查时间；移动端保留卡片。配置弹窗保持字段与顺序，提交区随滚动保持可见。
7. **细节**：控件8px、面板12px、弹窗16px圆角；明确行选中、悬停与键盘焦点。弹窗限制背景滚动，支持Tab循环、Esc关闭与焦点返回。
8. **视觉**：2FA六步列表改为相连节点轨道，使用已有步骤、状态和错误信息。用量概览以真实读数为主，移除重复小进度条；账号行保留有意义的窗口占用条。未生成图片，也没有添加虚构趋势或数据。
9. **动效**：反馈统一为150ms颜色变化，弹窗使用200ms、4px的进入反馈；只保留真实加载状态的旋转，遵循减少动态效果偏好。

## 验证

- 127项测试通过；TypeScript / Vue类型检查与生产构建通过
- 三轮渲染检查：基线、第一版、最终版；覆盖登录、账号、配置弹窗、设置与手机界面
- 在隔离数据库和模拟账号上检查320/375px布局、选择账号、暂停/恢复、配置提交、弹窗按钮可见性、键盘焦点、Esc关闭与减少动态效果
- 未对真实账号执行2FA、授权或凭据导入
