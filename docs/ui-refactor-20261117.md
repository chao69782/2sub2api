# 工作台界面优化 · 2026-11-17

## 审视与方向

现有页面已采用浅色与深绿，无渐变、发光或装饰 emoji，本次按 unslop 的轻量优化模式处理。

- 产品：供管理员处理 OpenAI 账号授权、凭据与 Sub2API 同步的工作台
- 性格：沉稳、精确、利落，沿用项目已确认的方向
- 语境：长时间使用的运维工作台，灰白工作面与少量深绿强调
- 重点：真实用量读数、可用时间与六步凭据操作进度
- 标记：由真实任务状态驱动的步骤轨道

审视发现：账号页搜索、筛选和主要操作挤在同一行；表格操作列占宽较大；设置页标题与字段层级接近；导入弹窗在手机上保留了过高的空结果区；样式存在相互覆盖的重复定义。

## 九轮调整

1. 间距：以 4px 为单位统一页面、面板、字段、工具栏和控件间距
2. 颜色：集中定义灰白、文字、边框、深绿和选中背景变量，主操作使用深绿
3. 图标：沿用 Lucide 18px / 1.5 描边，移除设置标题的重复装饰图标
4. 文案：说明授权、凭据与同步的页面用途，明确导入格式、空状态与无效输入提示
5. 字体：中文系统无衬线字体配合等宽数字，统一标题、正文与辅助信息层级
6. 布局：将搜索、筛选和批量导出归入列表；桌面表格最小宽度从 1480px 降至 1280px；设置采用说明与字段分区；手机保留账号卡片
7. 细节：共享控件、提示和弹窗使用统一圆角；弹窗标题固定、内容独立滚动；保留 Tab 循环、Esc 关闭和焦点返回
8. 视觉：读数与真实步骤承载重点，沿用实际产品内容，无生成图片
9. 动效：统一缓动，保留真实加载反馈，支持减少动态效果

点击选中的外框、输入框焦点变色、行焦点框、配置选择框高亮边框与导航选中下划线已移除。选择状态用背景、文字和原生勾选表示；键盘操作使用下划线与背景反馈。

添加账号只有一个“导入”按钮，一次点击自动检查并导入有效行。无有效行或请求失败时在弹窗中显示提示；修改数据会清除旧结果。提交期间禁用重复提交和编辑。
