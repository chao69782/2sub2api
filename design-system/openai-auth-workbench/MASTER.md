# 账号授权工作台 · 界面规范

更新：2026-11-17。当前实现以本文件和 src/client/style.css 为准。

## 方向

管理员用于 OpenAI 账号授权、凭据与 Sub2API 同步的运维工作台。沿用浅色与深绿，性格为沉稳、精确、利落。视觉重点是实际用量、预计可用时间和任务驱动的六步操作轨道。

## 色彩

| 用途 | 值 |
| --- | --- |
| 页面 | #f6f7f7 |
| 工作面 | #ffffff |
| 主要文字 | #17251d |
| 次要文字 | #4b5952 |
| 辅助文字 | #64736b |
| 分隔线 | #e1e6e3 |
| 控件边框 | #c6ceca |

| 主操作悬停 | #065f46 |

颜色变量集中在共享样式的 :root。正向、警告和错误状态需同时显示文字。页面保持浅色，浏览器原生控件使用 light color-scheme。

## 字体与间距

- 界面：Segoe UI、Microsoft YaHei UI、PingFang SC、Microsoft YaHei、系统无衬线字体
- 数字和配置值：Cascadia Code、SFMono-Regular、Consolas、等宽字体
- 页标题 28px，手机 24px；主要读数 30–36px；正文 14px；辅助信息 12–13px
- 字重以 400 / 500 为主，数字采用 tabular-nums
- 以 4px 为单位，页面边距 16 / 32px，面板内边距 20 / 24px，分区间距 20 / 24px
- 默认输入与按钮高 44px；表格紧凑操作高 36px，手机账号操作保持 44px
- 控件圆角 8px，面板 12px，桌面弹窗 16px

## 布局与交互

- 保留顶栏与账号、设置两个导航项，内容最大宽度 1600px
- 账号页依次为页面动作、用量概览、账号列表；搜索、状态筛选和导出属于列表工具栏
- 桌面表格在自身容器内滚动，操作列固定；手机使用账号卡片
- 设置使用标题说明与字段两列，窄屏纵向排列，保存操作保持可见
- 弹窗标题固定，内容区域独立滚动，支持 Tab 循环、Esc 关闭与焦点返回
- 用户要求所有点击选中状态不增加外框或强调边框；通过浅色背景、文字和原生勾选表达选择，键盘焦点使用背景或下划线
- 添加账号只有一个导入按钮，自动执行检查并导入有效行；错误就近显示，修改数据后清除旧结果
- 保留 150ms 反馈和 180ms 弹窗进入，统一 cubic-bezier(0.22, 1, 0.36, 1)，支持 prefers-reduced-motion
